# Galería Interactiva

Una aplicación web simple que permite:
- Agregar imágenes mediante URL.
- Seleccionar una imagen (se resalta).
- Eliminar la imagen seleccionada.

Desarrollado con HTML, CSS y JavaScript 
## Cómo usar
1. Abre `Index.html` en tu navegador.
2. Ingresa una URL de imagen válida (ej: `https://picsum.photos/200`).
3. Haz clic en "Agregar Imagen".
4. Selecciona una imagen de la galería.
5. Usa "Eliminar Imagen Seleccionada" para borrarla.

> ✅ Proyecto compatible con GitHub Pages.

## Tecnologías
- HTML5
- CSS3 (Grid, Flexbox, Transiciones)
- JavaScript (Manipulación del DOM, Eventos)
